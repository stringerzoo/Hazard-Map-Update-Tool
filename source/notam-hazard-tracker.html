How to Use — Monthly Workflow

Overview

This tool parses FAA obstruction NOTAM PDF exports, identifies unlit towers and stacks meeting your height and range criteria, and produces a report of towers to add or remove from your base hazard map, along with a KML overlay for ForeFlight or Google Earth. Run once a month.

Step 1 — Get the NOTAM report

  1. Click FAA NOTAM Search ↗ in the top-right corner.
  2. Select Geography search type.
  3. Enter your base airport identifier, hospital identifier, or Lat/Lon coordinates and set radius to 70 NM.
  4. Under Filter, select Obstruction. Select all and export as PDF.
⚠ The tool’s Max Range must match the FAA query radius. The mismatch detector flags differences over 1 NM.

Step 2 — Load reports

Drop the current month PDF into the right zone. Optionally drop last month’s export PDF into the left zone for a differences analysis, showing which obstructions to add, keep, and remove.

Step 3 — Check settings

  • Base — select from the dropdown. Coordinates fill automatically. Use the Manual coordinate override section for bases not yet in the list (e.g. AE 189). The Airport ID and Base Name fields there affect only the header display and mismatch detection labels — they do not permanently modify the base list.
  • Min AGL — hazard map threshold. Default: 500 ft.
  • Buffer — KML-only band below min AGL. Default: 50 ft.
  • Max range — towers beyond this excluded. Default: 70 NM.

Step 4 — Click Parse & Report

  • Remove — pull dots from hazard map.
  • Keep — no change needed.
  • Reissued — same physical tower, NOTAM number changed. No map update needed. The tool detects these automatically by matching coordinates between the Remove and Add lists.
  • Add — plot on hazard map.
  • Buffer Zone — KML only, do not plot on map.
  • Out of Range — entries that meet the height filter but fall outside your max range setting. The FAA’s geography search uses a bounding box rather than a precise circle, so it sometimes returns towers beyond the stated radius — occasionally by a significant distance. These are listed here for transparency so you can confirm they were seen and correctly excluded, not silently dropped.

Step 5 — Update hazard map & export

Work through Remove and Add to update the wall map. Then click Export KML for ForeFlight and import in ForeFlight or Google Earth.

Export CSV produces a full spreadsheet of results with one row per tower, including action (ADD / KEEP / REMOVE / REISSUED / BUFFER), range, bearing, MSL, AGL, and the original NOTAM location reference. Useful for record-keeping, month-to-month comparison, and validating parser output during testing.

Tip: To save the on-screen report as a PDF, use your browser’s File → Print → Save as PDF function.

Notes

  • All settings are saved to your browser automatically.
  • 156 AEL bases are pre-loaded. Use manual override for unlisted bases.
  • Coordinates shown and entered in DD MM.mmmm format.
  • This tool runs entirely in your browser. No data is sent anywhere.
