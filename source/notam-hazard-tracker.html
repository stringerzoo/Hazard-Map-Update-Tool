How to Use — Monthly Workflow

Overview

This tool parses FAA obstruction NOTAM PDF exports, identifies unlit towers and stacks meeting your height and range criteria, and produces a hazard map diff and a ForeFlight KML overlay. Run it once a month after pulling a fresh NOTAM report.

Step 1 — Get the NOTAM report

  1. Click FAA NOTAM Search ↗ in the top-right corner.
  2. Acknowledge the disclaimer.
  3. Select Geography search type.
  4. Enter your base airport identifier: 6I2
  5. Set radius to 70 NM.
  6. Under Filter, select Obstruction.
  7. Select all results and export as PDF.
⚠ The tool’s Max Range setting must match the radius used in the FAA query. The mismatch detector will flag a difference of more than 1 NM. Some entries slightly outside the stated radius may appear in FAA results — the range filter here will exclude them and list them in the Out of Range section.

Step 2 — Load the reports

Drop the current month PDF into the right drop zone. Drop last month's PDF into the left zone to enable the Remove / Keep / Add diff. On first run, leave the previous zone empty — all results will appear as Add.

⚠ Both PDFs should be queried from the same reference point and radius. If they differ, the tool displays an amber warning banner after parsing.

Step 3 — Check settings

Open Filter & Alert Settings and verify:

  • Min AGL — your operational threshold. Towers at or above this appear in the full diff and are candidates for the hazard map. Default: 500 ft.
  • Buffer below min AGL — towers within this band below the min AGL threshold are parsed and included in the KML overlay for in-cockpit awareness, but are not included in the hazard map diff. Default: 50 ft (captures towers down to 450 ft AGL at default settings). See CONFIGURATION.md for operational rationale.
  • Max range (NM) — towers beyond this from 6I2 are excluded from the map and KML but listed in Out of Range. Default: 70 NM.
  • Alert levels — three severity tiers for qualifying towers, plus a separate Buffer color, all controlling KML icon colors in ForeFlight.

Step 4 — Run the diff

Click Run Diff. Results appear in four sections:

  • Remove — in last month, not this month. Pull these dots from the hazard map.
  • Keep — in both reports. No map change needed.
  • Add — new this month. Plot these on the hazard map.
  • Out of Range — meet height filter but exceed max range. Do not plot; listed for audit purposes only.

Step 5 — Update the hazard map

Work through the Remove and Add sections to update the physical wall map at your base.

Step 6 — Export KML for ForeFlight

Click Export KML for ForeFlight. The KML contains all current qualifying towers and stacks within your max range, color-coded by alert level.

To import: save the .kml file, then in ForeFlight go to Maps → Layers → Import File. Replace the previous month's layer each time.

Configuration notes

  • Reference point is hardcoded to 6I2 (Lebanon Muni, 37.5617°N 85.1450°W). To use at a different base, edit the REF constant in the script.
  • Alert level settings reset to defaults on each page load. Persistent settings are planned for a future version.
  • This tool runs entirely in your browser. No data is sent anywhere.
